\# Git HOL 1



\## Objective

Learn basic Git commands and push a local repository to GitHub.



\## Commands Performed



```bash

git init

touch welcome.txt

echo "Welcome to the version control" > welcome.txt

git status

git add welcome.txt

git commit

git remote add origin

git remote -v

git branch -M main

git push -u origin main

```

\## Result


\- Git repository initialized successfully.

\- welcome.txt created successfully.

\- Commit created successfully.

\- Repository pushed to GitHub successfully.
